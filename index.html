Stop rebuilding projects by hand

Claude only merges a personal account into a work one when both use the same email, and then it moves everything. Any other move meant doing it piece by piece.

By hand

  • Download every file, one by one
  • Copy and paste the instructions
  • Create the project again from scratch
  • Paste old chats back in, one at a time
  • Lose what Claude remembered

With Ferry

  • Save the whole project as one ZIP
  • Log in to the other account
  • Bring it in with one click
  • Memory comes along as CONTEXT.md

Questions

Is Ferry made by Anthropic?

No. Ferry is an independent tool. It is not made, endorsed or supported by Anthropic. Claude is a trademark of Anthropic.

Is it free?

Yes. Ferry is free to install and use.

Doesn't Claude already do this?

Only in one case: when you join a Team or Enterprise plan with the same email as your personal account, Claude can move that whole account into it. It cannot move between different emails, from a work account to a personal one, or between two personal accounts, and you cannot choose what moves. Ferry handles all of those.

Which accounts does it work with?

Any claude.ai account you can log in to in Chrome. Ferry works on the claude.ai website, not inside the desktop or mobile apps.

Does it move what Claude remembers?

Project memory comes as a CONTEXT.md file in the new project, so Claude can read it from the first chat. Account memory is optional and comes as an ABOUT-ME.md file.

Why not bring every chat into the project?

Projects have a size limit and long chats fill it quickly. Ferry ticks the recommended items and shows the size before you import. Every chat stays saved in the ZIP file.

Which browsers are supported?

Chrome. Other Chromium browsers such as Edge or Brave may work, but they are not tested yet.

Will it keep working?

Ferry uses the same pages claude.ai uses. If claude.ai changes, a feature may stop working until Ferry is updated.
